ROOT CAUSE
The released challenge selects rag_slow. When this incident is enabled, app/mock_rag.py deliberately sleeps for 2.5 seconds inside retrieve(). The measured ~2652 ms application latency and consistent impact across all refund requests match that injected retrieval delay. Cost, error and quality stayed broadly stable, isolating the symptom to latency rather than failure, token or quality degradation.

FIX ACTION
Disable the faulty incident/dependency path, add a strict retrieval timeout and serve a safe fallback response when retrieval exceeds the latency budget.

PREVENTIVE MEASURE
Instrument retrieve and generate as child spans, alert when P95 exceeds 3000 ms for five minutes, add dependency latency metrics and circuit-breaker/timeout tests, and verify recovery with the same workload after mitigation.
